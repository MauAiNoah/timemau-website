# Public claims register

Status vocabulary:

- **Current** — true of this public website now.
- **Validated prototype** — demonstrated in development, not a released guarantee.
- **Product principle** — an architecture or behavior the product is being designed to uphold.
- **Planned** — not part of the current release.
- **Aspirational** — a mission-level direction, not availability.

| Public claim | Classification | Qualification and use |
|---|---|---|
| MauAI is in active development. | Current | Displayed in the global announcement and pre-launch pages. |
| This website is static and uses no first-party analytics, advertising pixels, external fonts, or marketing cookies. | Current | Describes the repository and deployed output only. GitHub may retain infrastructure logs. |
| The early-access form is being prepared. | Current | Mode is `disabled`; no submission endpoint or invented contact address exists. |
| Public downloads are unavailable. | Current | No artifact URLs, versions, dates, checksums, or active download controls exist. |
| The library is the product; AI is the librarian. | Product principle | Positioning and architecture metaphor, not a feature-availability claim. |
| MauAI is being built to show the document, passage, and page behind a library-backed response. | Product principle | Traceability is the design contract; correctness of the author is not guaranteed. |
| When the documents do not support an answer, the librarian is designed to stop or offer a deeper search. | Product principle | No claim of zero hallucinations or perfect abstention is made. |
| Free conversation is kept distinct from library evidence. | Product principle | Must remain visibly labelled in the product. |
| The product core is local-first and has no silent cloud fallback in the planned architecture. | Product principle | Does not mean unhackable, completely private, or immune to user/device/network risks. |
| Personal-library data stays on the computer in the planned local flow. | Product principle | Optional future online features require separate, visible consent and disclosures. |
| Models can change while the library remains. | Product principle | Describes ownership and portability priorities. |
| PDF, TXT, and Markdown are first-version document targets. | Planned | Not presented as a commercially available import guarantee. |
| macOS and Windows are commercial targets. | Planned | No simultaneous launch or compatibility guarantee. |
| 16 GB RAM is the provisional target. | Planned | Under validation on real hardware; not a universal system requirement. |
| Noah Core Seed is being curated from legally distributable material. | Planned | Not downloadable and not represented as complete. |
| Phone and tablet access is planned as a browser companion for v1.x. | Planned | Not part of the first desktop core; computer remains the intended processing host. |
| Knowledge navigates. We get you there. | Aspirational | Official brand tagline, not a product-performance guarantee. |

## Prohibited wording

Do not add:

- revolutionary;
- perfect accuracy;
- hallucination-free;
- absolute truth;
- guaranteed correct;
- best AI;
- AGI;
- knows everything;
- replaces experts;
- unhackable;
- fully private without qualification;
- available now before signed builds and validation.

Any new public claim must be classified here before release.
